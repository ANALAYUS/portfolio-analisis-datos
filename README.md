# Portfolio de Análisis de Datos

¡Hola! 👋 Bienvenidos a mi repositorio de proyectos de análisis de datos. Aquí comparto desarrollos prácticos enfocados en la resolución de problemas de negocio, limpieza de datos, modelado y visualización utilizando herramientas como **Python, SQL y Power BI**.

---

## 🚀 Proyectos Incluidos

### 1. Análisis de Ventas y Rendimiento Comercial (Python)
* **Herramientas:** Python, Pandas, NumPy, Matplotlib.
* **Descripción:** Limpieza de un dataset de 50,000 registros, tratamiento de nulos, estructuración temporal y detección de patrones de consumo y rentabilidad por región.

### 2. Auditoría de Cartera de Clientes y Transacciones (SQL)
* **Herramientas:** SQL Server / PostgreSQL.
* **Descripción:** Desarrollo de consultas avanzadas utilizando `JOINS`, funciones de agregación, CTEs y subconsultas para auditar comportamientos de pago y segmentación de clientes VIP.

  
### 3. Dashboard Interactivo de Rendimiento Comercial (Tableau)
* **Herramientas:** Tableau Public, Modelado de Datos.
* **Descripción:** Diseño y desarrollo de un tablero interactivo orientado a directivos para el seguimiento de KPIs comerciales (ventas totales, cumplimiento de metas, rentabilidad por categoría y análisis geográfico).
* **Funcionalidades:** Uso de filtros cruzados, parámetros dinámicos, campos calculados en Tableau y diseño enfocado en la experiencia de usuario (UX) para facilitar la lectura rápida de métricas clave.
